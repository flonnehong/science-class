# 두근두근 중2 과학 — 통합 수업 앱

- `index.html` 학생용 처음 화면 · `lesson.html?l=차시` 차시 수업 · `teacher.html` 통합 교사용
- `core.js` 로그인·쪽 넘김·글자 크기·시계·실시간 진행·답 저장 (모든 앱이 함께 씀), `adapt.js` 다른 저장소의 수업 자료에 붙이는 연결 프로그램
- `data.js` 7단원 차시 내용, `sims.js` 움직이는 모형, `catalog.js` 차시 목록
- 미리 보기(저장 안 함): 주소 뒤에 `?demo=1` 또는 `&demo=1`
- 실시간 진행은 Firebase Realtime Database, 결과 기록은 교사용 페이지가 Apps Script를 거쳐 구글 시트로 보냅니다. 이름은 받지 않습니다.
- `fb.js`의 Firebase 웹 설정값은 공개되어도 되는 값이며, 접근은 데이터베이스 보안 규칙이 제한합니다. 교사 비밀번호와 등록 코드는 저장소에 없습니다.
